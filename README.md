### Requirements:

- Display tasks across 4 columns
- Create, update, and delete tasks
- Drag-and-drop tasks between columns
- Pagination or infinite scroll in each column
- Search bar to filter tasks by title or description
- Use Material UI or Bootstrap for layout and components
- Cache data using React Query

### UI Requirements:

- Grid with 4 columns (Backlog, In Progress, Review, Done)
- Each container has a header with column name and task count
- Each container has an Add Task button
- Responsive design (1 col mobile / 2 col tablet / 4 col desktop)

## What we made ✅

### Features:

- ✅ 4 column Kanban board (Backlog, In Progress, In Review, Done)
- ✅ Create tasks with title, description, and priority via Modal
- ✅ Edit tasks with pre-filled Modal
- ✅ Delete tasks instantly with optimistic update
- ✅ Drag and drop tasks between columns with order persistence
- ✅ Priority badges with colors (High / Medium / Low)
- ✅ Skeleton loading UI using Material UI
- ✅ Data caching using React Query
- ✅ Local state management for instant UI updates
- ✅ 3-dot menu on each task card for Edit and Delete
- ✅ Responsive grid layout

### Tech Stack:

- Next.js
- React Query (TanStack Query)
- @hello-pangea/dnd (Drag and Drop)
- Material UI (Skeleton)
- Supabase (Database)
